SankeyFlow for Excel (Windows desktop)

To install:
1. Unzip this folder (right-click the zip > Extract All). Don't run it from inside the zip.
2. Close Excel.
3. Double-click "Install SankeyFlow.cmd".
   If Windows says "Windows protected your PC", click "More info" then "Run anyway"
   (the scripts aren't signed).
4. Open Excel. The SankeyFlow button is on the Home tab. If you don't see it right away, click Add-ins in the top right corner and it should be there under Developer Add-ins.

Updates arrive automatically; there's no need to reinstall.

To remove it, close Excel and double-click "Uninstall SankeyFlow.cmd".

Needs Microsoft 365 / Excel 2016 or later on Windows, and an internet connection.
